# opencascade-sys (generated fork)

Rust bindings to Open CASCADE Technology (OCCT) 8.0.1 through [cxx](https://cxx.rs), in the style of [bschwind/opencascade-rs](https://github.com/bschwind/opencascade-rs)'s `opencascade-sys`: one cxx bridge per OCCT package, opaque OCCT classes, `UniquePtr` ownership and `Handle_*` typedefs for `opencascade::handle`.

Unlike upstream, the bridges are generated by [`occt-bindgen`](../occt-bindgen) from the OCCT headers instead of being written by hand, and every function that can reach OCCT returns `Result`, so an OCCT exception becomes a `cxx::Exception` instead of terminating the process.

## Provenance

Forked from opencascade-rs at commit `32758df23a137f4e7c786c618b0317fc3badb3b2` (LGPL-2.1, see `LICENSE`). Kept from upstream: the `OCCT/CMakeLists.txt` package probe and the OCCT discovery in `build.rs`. Replaced: every hand-written bridge in `src/` and wrapper header in `include/` (now generated), the static `builtin` OCCT 7.8.1 feature (Caddy links OCCT 8.0.1 dynamically), and the version gate (the generated bindings require exactly the OCCT minor version they were generated from).

## Layout

| Path | Origin |
| --- | --- |
| `bindings.toml` | Hand-maintained allowlist of OCCT classes, enums and collections |
| `src/*.rs`, `include/generated/*.hxx`, `occt-toolkits.txt` | Generated; do not edit |
| `bindings-report.md` | Generated; lists every skipped member with the reason |
| `include/bindings_common.hxx` | Hand-written runtime: exception translation, handle access, `OcctStream` |

## Conventions

- Members cxx can bind directly are methods on the class (`maker.pin_mut().Shape()?`); static members use `#[Self]` (`BRepGProp::LinearProperties(...)`).
- Everything else goes through a generated C++ shim named `<Class>_<Member>`: constructors (`gp_Pnt_new_real3`), by-value returns (`TopoDS_Shape_Reversed`), handles, strings and streams.
- Overloads are suffixed with their parameter types (`Init_ax2_real3`); constructors are always suffixed.
- Transient classes are constructed as `UniquePtr<Handle_<Class>>`; use `Handle_<Class>_get` / `_get_mut` to reach the object and `Handle_<Class>_to_<Base>` / `_from_<Base>` to cast.
- `std::ostream` / `std::istream` parameters take an `OcctStream` (`occt_stream` module), an in-memory binary stream.

## Regenerating

```sh
node packages/occt-native/scripts/build-occt.ts         # once: builds OCCT 8.0.1
node packages/occt-native/scripts/generate-bindings.ts  # needs libclang (Xcode / libclang-dev)
node packages/occt-native/scripts/generate-bindings.ts --check
```
