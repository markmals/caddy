# Corresponding source

`@roonieone/occt-native` and its per-platform packages contain Open CASCADE Technology (OCCT) 8.0.1 and FreeType 2.14.3 built as shared libraries, plus `occt-native.node`, compiled from the Rust and C++ sources in this package (`crates/`).

## The addon

| Path | Contents |
| --- | --- |
| `crates/occt-neon` | Neon addon (Apache-2.0). `src/gordon` is a Rust port of ocp_gordon 0.3.1 (Apache-2.0, Copyright 2018 German Aerospace Center (DLR)); `src/gordon/optimize.rs` also ports SciPy (BSD-3-Clause) |
| `crates/opencascade-sys` | cxx bindings to OCCT (Apache-2.0), generated by `crates/occt-bindgen` from `bindings.toml`; no third-party code — the crate began as a fork of bschwind/opencascade-rs and keeps its naming conventions, but every bridge, header and build step is ours |
| `crates/occt-bindgen` | libclang generator that writes `opencascade-sys` from the OCCT headers (Apache-2.0; build-time only) |
| `scripts/build-occt.ts` | builds OCCT and, through `scripts/build-freetype.ts`, FreeType into the same prefix |
| `scripts/build-native.ts` | builds the addon and stages it with those libraries |

Rebuild with `node scripts/build-occt.ts && node scripts/build-native.ts --release`, using a Rust stable toolchain, CMake, Ninja and a C++17 compiler.
