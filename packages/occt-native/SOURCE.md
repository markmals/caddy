# Corresponding source

`@roonieone/occt-native` and its per-platform packages contain Open CASCADE Technology (OCCT) 8.0.1 built as shared libraries, plus `occt-native.node`, compiled from the Rust and C++ sources in this package (`crates/`).

## OCCT

|  |  |
| --- | --- |
| Upstream | https://github.com/Open-Cascade-SAS/OCCT |
| Tag | `V8_0_1` (commit `b8f597c677811d1f9f4d8a97f5ae2825c0353a42`) |
| Archive | https://github.com/Open-Cascade-SAS/OCCT/archive/refs/tags/V8_0_1.tar.gz |
| SHA-256 | `0d6913eae4bcc09a3653ceced6dda1aec11c35a1513d4c06762c9b002092c68a` |
| Build | `scripts/build-occt.ts`, unmodified sources; the exact CMake options are recorded in each platform package's `occt-build.json` |

## The addon

| Path | Contents |
| --- | --- |
| `crates/occt-neon` | Neon addon (LGPL-2.1-only) |
| `crates/opencascade-sys` | cxx bindings to OCCT, generated by `crates/occt-bindgen` from `bindings.toml`; fork of bschwind/opencascade-rs `opencascade-sys` (LGPL-2.1) |
| `scripts/build-native.ts` | builds the addon and stages it with its OCCT libraries |

Rebuild with `node scripts/build-occt.ts && node scripts/build-native.ts --release`, using a Rust stable toolchain, CMake, Ninja and a C++17 compiler.
